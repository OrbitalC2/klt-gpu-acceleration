GPU IMPLEMENTATION:
------------------
- Target: _convolveSeparate (85.94% D1 hotspot)
- Thread blocks: 16×16 (256 threads)
- Grid size: Dynamic based on 1920×1080 resolution
- Memory: Global memory access
- Kernel: Separable 2D convolution (horizontal + vertical)

ANALYSIS:
--------
GPU performance currently matches CPU baseline due to:
1. Memory transfer overhead (H2D and D2H)
2. No shared memory optimization
3. Global memory bandwidth limitations
4. Kernel launch overhead
5. No stream concurrency

This is EXPECTED for V2 naive implementation.
